# UA16 — MINMAX de uma matriz

**Linguagem:** VisuAlg

## O problema
Lê uma matriz 5x5, acha o menor elemento e depois o maior valor da linha dele (o MINMAX).

## O que pratiquei
matrizes, laços aninhados

## Como rodar
Abra no VisuAlg e pressione F9.
