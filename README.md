# Pensamento Computacional

Desafios que resolvi na disciplina **Pensamento Computacional** do curso de **Análise e Desenvolvimento de Sistemas (UNIVALI)**, no 1º trimestre.

Os exercícios vão do pseudocódigo ao **VisuAlg** e depois à linguagem **C**, mostrando a evolução da lógica de programação.

## Desafios

| UA | Desafio | Linguagem | Conceitos |
| --- | --- | --- | --- |
| UA3 | [Checklist diário](UA03-checklist-diario/) | Pseudocódigo | sequência, condição (SE), repetição (PARA) |
| UA5 | [Número invertido](UA05-numero-invertido/) | VisuAlg | `div`, `mod`, atribuição |
| UA7 | [Consumo de energia](UA07-consumo-energia/) | VisuAlg | variáveis e tipos, operações aritméticas |
| UA9 | [Ingressos de cinema](UA09-ingressos-cinema/) | C | `printf`, `scanf`, `if/else` |
| UA10 | [Comissão de vendedores](UA10-comissao-vendedores/) | VisuAlg | estrutura condicional (`se`) |
| UA11 | [Cálculo de frete](UA11-calculo-frete/) | VisuAlg | condicionais aninhadas, menu |
| UA12 | [Pedra, papel e tesoura](UA12-pedra-papel-tesoura/) | C | `rand`/`srand`, operadores lógicos (`&&`, `||`) |
| UA13 | [Enquete de sistemas operacionais](UA13-enquete-so/) | C | `while`, `switch`, contadores |
| UA14 | [Correção de uma calculadora em C](UA14-correcao-calculadora/) | Relatório | depuração, `do-while`, `switch` |
| UA15 | [Média da turma com vetor](UA15-media-turma-vetor/) | C | vetores, `for` |
| UA16 | [MINMAX de uma matriz](UA16-minmax-matriz/) | VisuAlg | matrizes, laços aninhados |

## Como rodar

- **C:** instale o GCC e rode `gcc arquivo.c -o programa && ./programa`
- **VisuAlg (`.alg`):** abra o arquivo no [VisuAlg](https://visualg3.com.br/) e pressione F9
