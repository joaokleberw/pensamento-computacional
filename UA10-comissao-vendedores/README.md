# UA10 — Comissão de vendedores

**Linguagem:** VisuAlg

## O problema
Calcula a comissão conforme o valor vendido (fixa, 2% ou teto) e o salário final.

## O que pratiquei
estrutura condicional (`se`)

## Como rodar
Abra no VisuAlg e pressione F9.
