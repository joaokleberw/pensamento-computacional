# UA12 — Pedra, papel e tesoura

**Linguagem:** C

## O problema
Jogo contra o computador, que escolhe uma jogada aleatória.

## O que pratiquei
`rand`/`srand`, operadores lógicos (`&&`, `||`)

## Como rodar
`gcc pedra_papel_tesoura.c -o jogo && ./jogo`
