# UA11 — Cálculo de frete

**Linguagem:** VisuAlg

## O problema
Calcula o frete por região, quantidade de peças (com desconto acima de 1000), distância e rastreamento opcional.

## O que pratiquei
condicionais aninhadas, menu

## Como rodar
Abra no VisuAlg e pressione F9.
