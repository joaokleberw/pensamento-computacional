# UA9 — Ingressos de cinema

**Linguagem:** C

## O problema
Mostra os filmes, lê o filme escolhido e a quantidade de ingressos e calcula o total a pagar.

## O que pratiquei
`printf`, `scanf`, `if/else`

## Como rodar
`gcc ingressos_cinema.c -o cinema && ./cinema`
